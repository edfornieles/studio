Voice & playback

Narrator settings

The Mother preset picks a calm British device voice and lowers the pitch slightly. It does not reproduce the recorded Water Cooler voice. That needs an authorised sample or a licensed voice on a narrator server.

The server turns each sentence into an audio file and keeps API keys on the server side (see docs/tts-backend.md). Audio is cached on this device. Lock-screen controls work with this narrator.

Playback diagnostics

If you hear nothing on iPhone, run these in order and copy the report.

  • The tone plays but the device voice stays silent: flip the ring/silent switch off and turn the volume up, then pick another voice above. Some voices must be downloaded first in Settings › Accessibility › Spoken Content.
  • Nothing plays at all: check Bluetooth/AirPlay routing. Open the page in Safari itself, not an in-app or Files preview.
  • The device voice stops when the phone locks. That's an iOS limit. Use a narrator server for lock-screen listening.
