# Finiliar Land (Neotopia: Data and Humanity)

## Short description

Fornieles contributed 'Finiliar Land' (2017) to Art Center Nabi's group exhibition 'Neotopia: Data and Humanity', which gathered artworks using data from various fields to imagine a more humane society. The Finiliar are creature-avatars whose emotional state is tied to live financial/market data.

## Core question

Can data be made humane — can people form caring, affective bonds with abstract data streams when those streams are embodied as living creatures?

## Social machine

Living 'Finiliar' creatures whose wellbeing is driven by live data feeds, making abstract data legible as emotional state.

## Fictional device

The Finiliar creature as a "body" for abstract data — here gathered into a *land* / world ("Finiliar Land"), staging the bestiary as an environment rather than single characters. (inference from title + wider Finiliar body of work)

## Real-world system it attaches to

Financial markets; data society. Shown within a curatorial frame — "Neotopia: Data and Humanity" — that gathers artworks using data "from various fields of the society, culture, politics, economics" to imagine a "more humane society." (fact for the frame; mechanic inferred from the wider Finiliar work)

## Audience / participant role

Museum visitor at the COMO venue, encountering Finiliar Land within a group show about making data humane — invited to feel toward data rather than merely read it. (inference)

## Performer / subject role

The creatures perform live data as mood/wellbeing; the subject portrayed is the data stream / market itself, consistent with the Arsenal and NFT iterations. (inference)

## Emotional engine

Empathy via cuteness — the show's explicit thesis ("more humane society") aligns with Fornieles' goal of fostering affective bonds with impersonal data. (fact for thesis; mechanic inferred)

## Ethical danger

As elsewhere in Finiliar: cuteness can aestheticise/soften the systems it depicts, and binding feeling to volatile data risks manipulation. Within a "humane data" curatorial frame this tension is foregrounded rather than hidden. (inference)
