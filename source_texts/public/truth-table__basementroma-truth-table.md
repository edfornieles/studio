# Truth Table — Ed Fornieles (Basement Roma)
_source: https://basementroma.org/exhibitions/ed-fornieles/ · accessed 2026-06-10_

**Exhibition Title:** Truth Table
**Dates:** October 26 – December 23, 2016
**Venue:** Basement Roma
**Text by:** Dorothy Howard. **All images:** Courtesy the artist. **Photos by:** Roberto Apa.

## Full text (as captured)

The exhibition converts the gallery into "a new VR product that allows the
viewer to occupy a changing host of bodies as they engage in a chain of sexual
interactions." The work employs randomization algorithms that contrast with
typical social-media algorithms, which create filter bubbles reinforcing user
preferences. Instead, Fornieles' approach offers "equally distributed variables"
that counteract expectations, producing experiences described as dream-like
rather than scientifically rigorous.

The installation engages with "the psychosomatic forms of relationality implied
by algorithmic content models, immersive virtual realities, and technologies of
sexuality."
